Metric definitions and historical coverage

Indicators count saved entries, including repeated values in separate entries. Profiles and tags count objects, not Case assignments. Samples count asset-manager sample archives, not extracted copies. Detection signatures count stored, classified signature files, regardless of line count. PDF attachments count once per stored attachment. Scripts use the explicit Scripts asset category.

Reference links include Case reference rows and profile OSINT records. Profile associations do not duplicate their attachments. Generated exports, backup archives, report images and unclassified attachments are excluded. Missing original dates are never inferred from Case creation or file modification times. Cumulative additions are recorded submissions, not historical inventory; deletions can make them differ from current inventory.

Pre-ledger deletions cannot be reconstructed. Deleted-content history is available only to Administrators with the relevant read permissions. Earlier dates are partial known coverage; blank chart periods before reliable coverage are unavailable, not zero. Asterisks mark partial date buckets. See the server's content-metric definitions for import and identity policies.
