Contextual completion

Classic YARA 4.5.4 curated assistance. Ctrl+Space opens the editor popup. Compiler checks are authoritative.



Condition snippets
Insert at cursor adds text without replacing a selection. Replace selection changes only the selected source. No Boolean operators or imports are added automatically.


Metadata conventions
Suggestions, not a required schema. Keys are user-defined. Values may be String, Integer or Boolean. Metadata is descriptive and is not a condition variable.

Style / performance guidance
Compiler warnings are shown separately. A successful sample match does not establish rule quality.


Compile and scan as data
Includes are disabled. Complete documents, imports and in-file dependencies are compiled together. Uploaded files are temporary; archives are scanned as stored bytes, without unpacking or execution. A successful match does not establish rule quality.


Official references
Target: classic YARA 4.5.4. Upstream documentation may describe later 4.5 releases. YARA-X is a separate compatibility target; its language server is not used for classic validation.
